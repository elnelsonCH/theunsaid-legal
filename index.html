The Unsaid — Privacy Policy

Last updated: October 21, 2026

This policy covers the internal publishing tool used by the YouTube channel The Unsaid (youtube.com/@theunsaidchannel-m4o). The tool is used only by the channel owner to manage the channel's own content. It is not offered to the public, and no other user can sign in to it.

What the tool does with YouTube API Services

  • Uploads and schedules the channel's own videos and Shorts, and sets their titles, descriptions, translations, thumbnails and playlists.
  • Uploads caption tracks for the channel's own videos.
  • Reads comments on the channel's own videos so the owner can reply, and posts the owner's replies and pinned-style comments.
  • Reads the channel's own YouTube Analytics and Reporting data to produce internal performance reports.

Data we access and store

  • OAuth tokens for the channel owner's own Google account, kept as environment secrets and never shared.
  • Public comment text and author display names on the channel's own videos, stored only in a private repository to draft replies.
  • Aggregated channel analytics (views, watch time, traffic sources), stored only in private reports.

We do not sell, share or transfer any of this data to third parties, and we do not use it for advertising.

Google and YouTube

This tool uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access granted to this tool can be revoked at any time at myaccount.google.com/permissions.

Retention and deletion

Stored comment drafts and reports are kept only as long as they are useful for running the channel and are deleted on request. Cached API data is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
